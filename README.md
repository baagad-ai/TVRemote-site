# The Remote — landing page

This public repository contains the landing page and privacy policy for The Remote, a free Android phone remote for compatible Android TV and Google TV. The Android application is maintained separately; this repository contains no app source, build outputs, signing files, or release credentials.

- Intended website URL after publication: https://baagad-ai.github.io/TVRemote-site/
- Intended privacy policy URL after publication: https://baagad-ai.github.io/TVRemote-site/privacy/

The site uses static files only. It has no account system, analytics, signup form, or cloud relay. Beta access remains unavailable from this page until the approved Google Play opt-in is configured; video remains a placeholder until the approved beta film is ready.

## GitHub Pages

After the public repository exists, set Pages to deploy from GitHub Actions. Then pushes to main will run the dependency-free site checks and deploy the site directory. Repository creation and Pages configuration are not yet complete. No secrets or deployment tokens are required.
