How do I install an Android app from a website instead of Google Play?

By The Remote · Sources reviewed 11 October 2026

Download the app's APK file on your Android phone, open it, and tap Install. The first time, Android asks you to allow installs from the app you downloaded with, usually your browser. Allow it, install, then turn that setting off again if you like.

The four steps

  1. Tap the download button on your Android phone.
  2. If Android asks, allow installs from your browser.
  3. Open the downloaded file and tap Install.
  4. Open the app.

Android asks once for permission to install from your browser

Android blocks installs from outside an app store until you allow them for a specific app, like Chrome or your file manager. The prompt takes you straight to the switch. You can turn it off again after installing.

Only install APKs from the developer's own site

Download the file only from the developer's official page. Android checks the app's signature before installing it. Some developers also publish a SHA-256 checksum so you can confirm the file matches what they released.

Updating means downloading the new version from the same page

An app installed this way doesn't update through an app store. Download the latest version from the same page and open it. Android installs it over your current app when the version and signing match. If Android refuses, keep the app you have and check the file came from the right page. Uninstalling first removes the app's saved data.

The Remote installs this way

The Remote isn't on Google Play. You download it from our website and install it on your phone in the steps above. The download section on our home page shows the current version, file size and SHA-256 checksum. Once it's installed, pick your TV and enter the code it shows.
