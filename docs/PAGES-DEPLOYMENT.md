The build independently checks its bytes and SHA-256 and stages only `/downloads/<sha256>/the-remote-<id>.apk`; the local path and binary do not belong in Git. Reject an APK above the Pages 25 MiB asset limit rather than publishing an incomplete download. Deploy using the existing authorized Wrangler with project `theremote-site`. Preview deployments retain the canonical production host and leave metrics disabled.

To publish, populate `site/config.js` with immutable `id`, direct HTTPS `.apk` `url`, `version` and lowercase SHA-256. The guard does not verify signing certificate or source provenance; those require independent release inspection.
